# Source-edition privacy / 소스 빌드 개인정보 안내

Last reviewed / 검토일: 2026-09-03

This describes the default, unmodified public source edition, not every fork or historical installer.

Palette's image, color and palette processing is local. The application code does not send those working materials to a PCSSAK server and does not add accounts, advertising analytics or automatic error uploads. Saved palettes, settings and exports remain on the device; protect backups and review files before sharing them.

The default source build does not enable the official updater. Dependency installation and builds can contact package registries and tool vendors. Opening external links, sending email or posting to GitHub uses those services and their own policies.

“Local processing” does not mean the entire computer makes no network connections. Windows and Microsoft WebView2 have their own update and diagnostic mechanisms. Microsoft describes required and optional WebView2 diagnostics and the applicable Windows settings in its [WebView2 privacy documentation](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy). This project does not claim to disable all operating-system or runtime communications.

If you voluntarily email support@pcssak.com or privacy@pcssak.com, PCSSAK receives the sender address, message and chosen attachments to handle the request. Incoming mail passes through Cloudflare Email Routing to a designated Gmail inbox; Cloudflare and Google process the mail as needed for those services. Do not send secrets, customer files or sensitive original images. Support correspondence is normally deleted within one year after resolution unless a legal retention obligation or dispute requires otherwise. Contact [privacy@pcssak.com](mailto:privacy@pcssak.com) to request access, correction or deletion as applicable.

Public GitHub posts and attachments may be copied, indexed or retained by others. Remove personal information before posting. Private security reports follow [SECURITY.md](../SECURITY.md).

[Cloudflare privacy](https://www.cloudflare.com/privacypolicy/) · [Google privacy](https://policies.google.com/privacy) · [GitHub privacy](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

기본 소스 빌드는 공식 자동 업데이트를 켜지 않습니다. 다만 의존성 설치·빌드·외부 링크·이메일·GitHub 이용에는 네트워크 연결이 생길 수 있고, Windows·WebView2의 별도 업데이트·진단 통신도 존재합니다. “로컬 처리”를 컴퓨터 전체의 네트워크 차단 보증으로 표현하지 않습니다.

공개 GitHub 게시물은 다른 사람이 복사·검색·보관할 수 있습니다. 민감한 보안 제보는 비공개 경로를 이용하세요. 이 안내는 임의로 수정한 배포본 전체에 대한 보증이 아닙니다.
